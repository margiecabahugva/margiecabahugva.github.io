# Margie Cabahug Portfolio Website

This is a responsive HTML/CSS/JS portfolio website based on the uploaded 9-page portfolio PDF.

## Design preservation
The website keeps the original portfolio's main visual direction:
- black and white layout
- oversized bold display headings
- clean, spacious sections
- original portfolio graphics/photos from the PDF
- original packages/rates and "How We Work Together" content

## Requested additions
- Services: Contract Drafting, Review, & Document Management
- Workflow sample: lease contract / renewal negotiation showing a requested 10% increase negotiated to 3% or 5%
- Workflow sample: contractor service agreement creation and document management
- Dance audition graphic caption placed below the image
- Running event graphic caption placed below the image

## Files
- `index.html` — website content
- `style.css` — visual design and responsive layout
- `script.js` — small navigation/footer behavior
- `assets/` — extracted images from the supplied portfolio PDF

## Publish for free
You can upload this folder to a static hosting service such as Netlify or GitHub Pages. No server/database is required.
